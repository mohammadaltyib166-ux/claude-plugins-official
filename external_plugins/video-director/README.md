# Video Director · مخرج الفيديو

مهارة لـ Claude Code تخرج فيديوهات يوتيوب والريلز والشروحات وتُنهيها باستخدام **FFmpeg** و **OpusClip** و **Blender**.
تبدأ بفهم المحتوى، ثم تقرر وتنفذ: الألوان، والانتقالات، والخطوط، والرسومات، والمؤثرات الصوتية، وحركة الكاميرا، واللقطات الثلاثية الأبعاد.

A Claude Code skill that directs and finishes videos with FFmpeg, OpusClip and Blender.

## ماذا تفعل

| المهمة | الأداة |
|---|---|
| فهم المحتوى: النص والتوقيتات والبنية ولحظات التركيز | OpusClip + `ffprobe` + كشف الصمت وتغيّر المشاهد |
| محرك الألوان: قياس، تصحيح، طابع لوني، مطابقة الكاميرات | `scripts/grade.py` |
| التايم لاين والانتقالات | `scripts/timeline.py` |
| الترجمة والعناوين بالعربية والإنجليزية | `scripts/make_captions.py` + `scripts/fetch_fonts.py` |
| الرسومات البرمجية: شريط تقدم، تظليل، صورة داخل صورة، تمويه | وصفات FFmpeg |
| المؤثرات الصوتية والموسيقى ومستوى الصوت | `scripts/sfx.py` + مكتبة OpusClip |
| حركة الكاميرا على اللقطات: تقريب مفاجئ، دفع بطيء، اهتزاز، Ken Burns | `scripts/camera_fx.py` |
| لقطات 3D: زوايا، عدسات، حركات كاميرا | `scripts/blender_shot.py` |

ويكتب Claude لكل فيديو ملف **`DIRECTION.md`** (دليل الإخراج) يحدد الطابع والخطوط والانتقالات والمؤثرات، ويعرضه عليك قبل أي عرض طويل.

## التثبيت

داخل Claude Code:
```
/plugin marketplace add mohammadaltyib166-ux/claude-plugins-official
/plugin install video-director@claude-plugins-official
```

> المهارة موجودة حاليًا على الفرع `claude/frontend-design-plugin-install-yfkq17`. إن لم يجدها الأمر فادمج الفرع في `main` أولًا.

## المتطلبات

- **FFmpeg** مع libass (موجود في جلسات Claude Code السحابية).
- **Python 3**، دون مكتبات إضافية للسكربتات.
- **Blender** للقطات 3D فقط، عبر حزمة `bpy`:
  ```bash
  python3 -m venv ~/.bpy && ~/.bpy/bin/pip install bpy
  ```
- **OpusClip** (اختياري): موصل AI Producer في حسابك على claude.ai.

**إذا كنت تعمل من الهاتف:** استخدم Claude Code على الويب (claude.ai/code). كل شيء يعمل في الحاوية السحابية، بما فيه Blender على المعالج، وجهازك لا يعرض شيئًا.

## أمثلة طلبات

- «اعمل ريلز من هذا الفيديو: ترجمة كلمة بكلمة، ألوان حيوية، مؤثرات صوتية على الانتقالات»
- «صحح ألوان الكاميرتين ليتطابقا، ثم طبّق طابعًا دافئًا»
- «أضف مقدمة ثلاثية الأبعاد فيها عنوان (الدرس الأول) بحركة دولي وإضاءة نيون»
- «اعرض لقطة الشاشة هذه على لوح ثلاثي الأبعاد يدور 40 درجة»
- «أضف تقريبًا مفاجئًا عند كل نقطة مهمة في الشرح»

## الأمان

- السكربتات لا تستخدم إلا FFmpeg ومكتبة Python القياسية، و`bpy` لسكربت Blender.
- لا تتصل بالإنترنت، باستثناء `fetch_fonts.py` الذي يحمّل خطوطًا مجانية (رخصة OFL) من مستودع google/fonts على GitHub.
- تكتب فقط في المسارات التي تحددها، ولا تعدّل ملفاتك الأصلية.

## الحدود المعروفة

- Blender لا يربط الحروف العربية في النص المجسّم، لذلك يُعرض النص العربي في 3D كبطاقة مسطحة (`type: text`).
- العرض في الحاوية السحابية على المعالج فقط: اللقطة بجودة draft تأخذ 2–8 ثوانٍ لكل إطار، فاجعل لقطات 3D قصيرة (2–4 ثوانٍ).
- توازن الأبيض التلقائي يخطئ في المشاهد التي يغلب عليها لون واحد. استخدم معها `--no-auto` أو `--match`.
